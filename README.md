# 로또 1등 연구소

재미로 하는 로또 번호 연구 웹앱입니다. 휴대폰 브라우저에서 바로 씁니다.

- **번호 뽑기**: 완전 랜덤 · 핫 번호 · 콜드 번호 · 균형형 · 핫3+콜드3, 고정수·제외수
- **통계**: 최근 당첨번호, 핫·콜드 TOP 6, 홀짝 비율, 번호별 출현 횟수
- **내 번호**: 저장한 번호를 추첨 뒤 자동으로 등수 확인 (이 기기에만 저장)
- **카페 글쓰기**: 연구 번호 · 주간 리포트 · 당첨 확인 글을 만들어 복사하고 카페를 엽니다

## 처음 한 번 설정

1. 저장소 **Settings → Pages** 에서 Source를 `Deploy from a branch`, 브랜치 `main` / `(root)` 로 저장
2. **Actions → draws → Run workflow** 로 당첨번호를 처음 받기 (전 회차, 몇 분 걸림)
3. `https://<아이디>.github.io/lotto-lab/` 접속 → 카페 글쓰기 탭에 카페 주소 입력

그 뒤로는 매주 토요일 밤 추첨이 끝나면 자동으로 당첨번호가 갱신됩니다.

로또는 매 회차 독립 추첨이라 지난 통계로 당첨 확률이 오르지는 않습니다. 재미로만 즐겨 주세요.
